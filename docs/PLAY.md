# 遊戲說明

《史前部落》是帶領一個史前部落求生的即時策略遊戲：派村民採集食物、木頭、石頭、骨頭，蓋小屋、倉庫、廚房、軍械庫等建築，讓部落壯大，再打敗敵人。這份說明介紹對局畫面怎麼操作；選單與設定見 [CLIENT.md](CLIENT.md)。

## 開始

- **戰役**：從教學開始，一關一關往下打；贏了一關就開放下一關。結果畫面按「下一關」直接開始下一關，按「戰役選單」回到關卡清單。第 1 關和第 5 關都有後半段，會在同一張地圖上直接接下去。打贏第 5 關的後半段就破關：結果畫面按「繼續」，在同一張地圖上看完結尾劇情「劇終」，回到關卡清單。
- **自訂遊戲**：在五張自訂地圖上對抗電腦。
- **多人對戰**、**無盡模式**：見選單裡的說明。
- 對局中可隨時存檔；選單的「讀取進度」或主選單的「讀取進度」可以接著玩。
- 自己一個人玩時，選單最下面有「測試：探索周圍」：營地周圍 192 格內立刻算探索過，看得到那裡的地形與其他部落的營地；無盡模式會先產生那片土地，新部落也照設定出現。和別人連線對局時沒有這個按鈕。

## 畫面

| 位置 | 內容 |
|---|---|
| 上方列 | 人口／居住空間（每間小屋 4 人）、食物、木頭、石頭、骨頭、倉庫裡的武器數；部落集合或全員備戰時右邊出現軍令圖示。用滑鼠時右邊還有暫停、速度（1×、2×、4×）與選單鈕 |
| 上方列下面的人數 | 正在採集食物（含打獵、肢解獵物、釣魚）、伐木、採石、撿骨頭的村民各有幾人，以及沒有工作的大人（笑臉）有幾人；只算在建築外面的人。點一個數字就選取那一類的下一個人並移過去，再點一次換下一個，輪完從頭開始；觀戰時只移過去 |
| 左上的訊息 | 有人出生或過世、建築完工、發現敵人、遭到攻擊等。點一則有位置的訊息（點在文字上），畫面會移過去；文字後面空著的地方照常是點地圖 |
| 右上的小地圖（第 3 關沒有） | 黃點是自己的村民、橘色是自己的建築、紅色（或其他部落的顏色）是別人的；暗的地方是看過但現在看不到，土色是還沒去過。白框是畫面看到的範圍，點或拖曳小地圖就移過去 |
| 小地圖下方的玩家清單（多人對戰、無盡模式的多人房間） | 每個部落的顏色、玩家名字與狀態，靠在畫面右邊。清單上方的按鈕（鍵盤是 Tab）顯示或隱藏清單，下次對局照樣記住；小地圖收起來時清單往上移 |
| 選取面板 | 選到的村民、建築或其他東西的資料與指令（見下方） |
| 大按鈕 | 橫向在右邊、直向在最下面：建造、軍隊、村民名單等（見下方） |

畫面可以隨時轉成直向或橫向，視窗也可以任意改大小，版面會跟著重排。

## 觸控操作

| 想做的事 | 怎麼做 |
|---|---|
| 選一個村民或建築 | 點它 |
| 選很多村民 | 按住地面一下再拖曳，框起來；或按「多選」鈕，之後點村民加入或移出選取、拖曳就是框選 |
| 叫村民去做事 | 選好村民後點目標：地面（走過去）、樹或石頭等資源（採集）、動物（打獵）、敵人或敵方建築（攻擊）、自己的建築（進去工作或休息）。點自己的倉庫會打開倉庫選單。下令時目標上會照原版閃一個小圖示（砍樹、採石、進建築、撿骨頭、採集或狩獵）；用滑鼠時，選好村民後移到目標上就先看得到，停在敵人或動物上時游標換成攻擊游標 |
| 叫村民用跑的 | 連點兩下目標 |
| 取消選取 | 按選取面板右上角的 ✕，或按 Android 返回鍵。選取村民時點空地是叫他們走過去，不會取消選取 |
| 移動地圖 | 單指拖曳；或點小地圖、點訊息 |
| 縮放 | 兩指捏合；在空地連點兩下放大 |
| 蓋建築 | 按「建造」→ 選建築 → 地圖上出現藍圖，綠格表示可以蓋、紅格不行；點地圖把藍圖移過去，按 ✔ 放下，按 ✕ 取消 |
| 暫停、選單 | 大按鈕的「暫停」與「選單」；Android 返回鍵依序取消放置、關閉面板、取消選取，最後打開選單 |
| 關閉面板 | 按面板的 ✕，或點面板外的地圖（提示與結果畫面要按裡面的按鈕） |
| 顯示或隱藏玩家清單（多人） | 按小地圖下方的清單按鈕 |

## 滑鼠與鍵盤

| 想做的事 | 怎麼做 |
|---|---|
| 選一個村民或建築 | 左鍵 |
| 加入或移出選取 | Shift＋左鍵 |
| 框選 | 左鍵拖曳（按住 Shift 加入原本的選取） |
| 叫村民去做事 | 右鍵點目標（同觸控的「點目標」）；右鍵拖曳是移動地圖，不會下指令 |
| 叫村民用跑的 | 連按兩下右鍵 |
| 取消選取 | 左鍵點空地、按 Esc，或按選取面板右上角的 ✕ |
| 移動地圖 | 右鍵或中鍵拖曳、方向鍵或 W A S D、滑鼠碰到視窗邊緣（可在設定關掉） |
| 縮放 | 滾輪、＋／－ |
| 蓋建築 | 選好建築後藍圖跟著滑鼠，左鍵放下（按住 Shift 可以連續放），右鍵取消 |

點建築：建築畫出來的任何地方都算，包括屋頂、瞭望塔上的平台與守衛。在建築裡面的村民（瞭望塔的守衛、在工作的人）不能單獨選取，點他就是選取那棟建築，建築面板的住戶頭像可以把他叫出來。村民站在建築前面時先選到村民；已經選著他時再點一次同一個地方（不是連點）改選後面的建築，再點一次又回到村民。對敵方建築也一樣：右鍵點它的屋頂或瞭望塔的平台就是叫村民去攻擊它。

## 選取面板

面板右邊的按鈕：

- ✕：取消選取，面板跟著收起。
- －／＋：把面板收成一個小標籤（村民的頭像與名字、選了幾人、建築名稱），仍然選著、照樣能下指令；按 ＋ 再打開。收起或打開會記住，下次選取照樣。
- 技能圖示（只在村民的面板）：這一局顯示或隱藏九項技能。每局開始時照設定的「村民面板預設顯示詳細資訊」（預設不顯示）。

點地圖選到的村民如果被打開的面板蓋住，畫面會往上（或往旁邊）移一點，讓他露在面板外面。

**一個村民**：頭像、名字、性別、年齡、生命，飽足（太低會餓）、體力（太低會累）、心情（太差的村民不聽命令，除非部落在備戰），現在在想什麼、拿什麼武器、搬什麼東西；顯示詳細資訊時另有九項技能（近戰、遠程、偵察、採集、打造武器、烹飪、DJ、巫術、建造）。按鈕：

- 碗：去吃東西（到最近的廚房）
- 月亮：去休息（到最近的小屋）
- 倉庫：打開最近的倉庫選單（拿武器或卸貨）
- 準星：把畫面移到他身上

**很多村民**：每個人的頭像，點一個就只選他；倉庫鈕與移過去的按鈕同上。

**建築**：名稱、等級、耐久、在做什麼（正常運作、升級中、修理中、建造中），裡面有誰。按鈕依建築而定：

- 升級、修理、取消升級、取消修理（游標停在按鈕上可看到費用）
- 拆除（會先問一次；工地拆掉就是取消建造）
- 住戶頭像：把那個人叫出來
- 軍械庫：每種武器的 －／＋ 決定要做幾件；陷阱的 ＋ 要再選一個地點放陷阱
- 聖殿：治療、防護、愛情藥水要再點一名成年村民；瘟疫要再點一個地點
- 倉庫：庫存數量

**別人的東西**（敵方村民、敵方建築、動物、資源）：只顯示資料。

## 選單

- **繼續遊戲**、**速度**（1×、2×、4×）
- **存檔**：自動存檔與 5 個存檔欄位，每格有縮圖、關卡、存檔時間與遊玩時間
- **讀取進度**
- **邀請區域網路玩家**（無盡模式）
- **設定**：語言、音樂音量、遊戲中顯示提示、滑鼠碰到邊緣捲動、介面大小、畫面（視窗或全螢幕，PC）、多人對局中顯示玩家清單
- **說明**、**任務目標**
- **放棄這局**（多人對戰；之後只能觀戰）
- **回到主選單**（會自動存檔）

從選單打開的存檔、讀取、設定、說明、任務目標，關掉後回到選單。

一個人玩時，打開選單（含存檔、設定、說明、任務目標）、建造清單、軍隊、提示或確認框時遊戲會停下，劇情開場黑邊合上的時候也會停一下；村民名單開著時遊戲照常進行。多人對戰不會因為這些停下。

## 劇情與提示

- 劇情出現時，點畫面任何地方翻到下一頁（右下角出現 ✔ 時才能翻）。
- 提示會說明部落現在的問題。村民喊餓或喊累時可以直接按「去吃東西」「去休息」；有些提示可以「看看在哪裡」。勾選「不再顯示提示」就關掉提示（酋長過世等重要提示仍會出現）。

## 輸贏

- 每一關的目標在開場劇情裡說明，也可以在「任務目標」再看一次。多半是打敗敵人，部落全滅就輸了。
- 結果畫面列出各部落的出生數、蓋好的建築、摧毀的敵方建築、擊敗的敵人、採集的資源與分數。

## 多人對戰

- 主機在大廳可以設定：開局保護（沒有、2、5、10、15、20 分鐘；預設 5 分鐘）、起始資源（標準、兩倍、四倍）、野生動物（有、沒有）。開局保護期間電腦部落不會出兵攻打任何部落，也不會追趕走進牠們領地的人。無盡模式的新世界另外可以選電腦難度，開局保護預設 15 分鐘。這些設定跟著存檔；無盡模式「繼續」列表上的每個世界都寫著它的設定。
- 小地圖下方的玩家清單列出每個部落的顏色、玩家名字與狀態；斷線的玩家顯示「離線」，他的部落暫時收不到指令，回來後繼續。部落很多時（例如無盡模式的大量電腦部落）清單只列前幾個，真人在前，最後一行寫還有幾個部落；全部的部落見「部落」面板。清單可以用上方的按鈕或 Tab 收起來。
- 在對局中加入（例如無盡模式的房間）時，一拿到自己的部落，畫面就移到自己的營地，看到的是自己部落的視野。
- 盟友共享視野：同一隊的部落、無盡模式結盟的部落，看得到彼此現在看到的地方，也共用探索過的土地；盟友設的陷阱與發現的陷阱也看得到。聯盟結束後，看過的土地仍留在地圖上，但看不到對方現在的動靜。
- 不在視野內的地方，建築維持你（或盟友）最後一次看到的樣子：之後才蓋的看不到，被摧毀的要等再看到那裡才會消失。投擲物、施工揚塵與別的部落之間的戰鬥也看不到；敵人攻擊你時，看得到牠站在哪裡。
- 放棄、部落被消滅，或以觀戰身分加入時只能觀戰：畫面可以自由移動，看得到所有真人玩家看到的地方（只有電腦部落看到的地方看不到），但不能下指令。
